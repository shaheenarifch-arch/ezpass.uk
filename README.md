# EasyPass - Travel City Passes
Premium affiliate site for Turbopass city passes via Awin.

## Deploy to GitHub Pages
1. Push this folder to your repo main branch (root)
2. GitHub Settings > Pages > Deploy from branch: main / (root)
3. Custom domain: ezpass.uk or explorepasses.com
4. DNS: CNAME to username.github.io or use Cloudflare Pages
