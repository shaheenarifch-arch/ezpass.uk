Paris Museum Pass vs Paris City Pass?

Paris Museum Pass = only museums (Louvre, Orsay, Arc de Triomphe, Versailles). Good if you only want museums.

Paris City Pass / EzPass = museums + tours + cruises + bus + discounts. Better value if you want Eiffel Tower, Seine cruise and city tours in same ticket.

For most 2026 visitors doing 3-4 things in 2 days, city pass saves €65-€120.
